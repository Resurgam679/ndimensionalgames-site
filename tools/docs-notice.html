NDVDB 1.1.0 is in review. These pages already describe it: the converter on macOS and Linux; up to 32 volumes composited at once, with each ray marching only the volumes it crosses; a shared brick pool that uses far less GPU memory; the scene compositor on OpenGL Core; and Surface Split by default near KWS2 and Crest water. It will be released as soon as the Unity Asset Store approves it. Until then, the current version converts on Windows x64 and composites up to 8 volumes in view.
